# vectorPath 默认快捷键

快捷键可在“管理 → 快捷键”中修改，也可使用 `CUI`、`SHORTCUTS` 或 `KEYBOARD`
命令打开设置界面。修改结果保存在当前用户配置中。

| 快捷键 | 默认功能 |
| --- | --- |
| `Ctrl+N` | 新建图形 |
| `Ctrl+O` | 打开图形 |
| `Ctrl+S` | 保存图形 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+P` | 打印 |
| `Ctrl+A` | 全选当前空间实体 |
| `Delete` | 删除选择集 |
| `L` | 直线 |
| `F1` | 使用帮助 |
| `F3` | 对象捕捉 |
| `F5` | 等轴测平面 |
| `F7` | 显示栅格 |
| `F8` | 正交模式 |
| `F9` | 栅格捕捉 |
| `F10` | 极轴追踪 |
| `F11` | 对象追踪 |
| `Ctrl+1` | 显示特性面板 |
| `Ctrl+3` | 显示工具选项板 |
| `Ctrl+9` | 显示命令行 |
| `Ctrl+K` | 命令搜索 |
| `Ctrl+L` | 聚焦命令行 |
| `Ctrl+Shift+T` | 生成加工刀路 |
| `F6` | 播放刀路仿真 |
| `Shift+F6` | 暂停刀路仿真 |
| `Ctrl+F6` | 停止刀路仿真 |
| `F12` | 刀路仿真单步 |
| `Ctrl+,` | 刀路仿真减速 |
| `Ctrl+.` | 刀路仿真加速 |
| `Ctrl+Shift+H` | 显示或隐藏刀路 |

没有预设组合键的功能也会显示在快捷键设置界面中，可由用户自行分配。设置界面会阻止
重复快捷键；“清除当前”只清除选中功能，“恢复全部默认”会删除全部用户覆盖。
