# vectorPath 全功能差距实施路线图

更新时间：2026-07-22

## 完成判定

任何功能只有同时满足以下条件才可在差距矩阵标记为 `complete`：

1. Ribbon 或属性页提供专属、主题感知图标和可访问名称。
2. 命令行提供完整命令名及常用别名，关键流程可以不依赖鼠标完成。
3. 交互命令提供动态几何预览、取消处理和明确提示。
4. 所有写操作通过 `SDocumentTransaction`，支持撤销和重做。
5. `.smartcad` 无损保存；交换格式不支持时生成兼容性报告。
6. 具有自动测试，且自研 `.h/.cpp` 均不超过 800 行。

## 持续更新规则

- 每次实现按功能 ID 更新 `s_autocad_gap_matrix.yaml`，并把源码证据加入
  `s_smartcad_feature_inventory.yaml`。
- 每次 Autodesk 大版本升级只新增或变更对应功能 ID，不重写稳定 ID。
- Ribbon 占位和停靠面板外壳标记为 `stub`，不能计入完成率。
