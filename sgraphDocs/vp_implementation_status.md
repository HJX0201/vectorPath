# vectorPath 实施状态

原始状态记录：2026-07-27；布局和输出证据校正：2026-09-23

## 已形成闭环的功能

- 深色、浅色和高对比度设计系统，紧凑 Ribbon、QtADS 工作区及主题图标。
- 直线、圆、三点圆弧、多段线、矩形、文字、线性标注和闭合边界填充。
- 多段线支持已确认线段、当前橡皮筋段和顶点标记动态预览；三点圆弧在指定端点时
  实时预览最终圆弧，共线状态显示辅助折线。
- PLINE/PL 可在绘制过程中用 ARC/A 与 LINE/L 切换圆弧段和直线段；圆弧段通过弧上点
  和端点生成真实 bulge，已确认弧段、当前三点圆弧和共线降级辅助线均实时预览。
  UNDO/U 会优先放弃待定弧上点或最后一段，结果沿用 `.smartcad` 与 DXF 42 组码往返。
- PLINE/PL 支持 `WIDTH/W 起始宽度 [终止宽度]`，每一段可独立保存起止宽度；直线段和
  bulge 圆弧段均以世界坐标渐变轮廓真实填充，绘制预览、选择范围、缩放范围、等比缩放、
  `.smartcad` v14 与 DXF LWPOLYLINE 40/41 组码往返已经自动测试覆盖。
- PEDIT/PE 支持预选或逐条选择多段线，并以单事务执行 CLOSE/OPEN、统一 WIDTH、
  REVERSE、DECURVE 和 JOIN；反向会同步反转顶点、bulge 方向与每段起止宽度，JOIN 会
  保留原曲线和渐变宽度。Ribbon 使用专属主题图标，U 可放弃上一次子编辑，Enter/右键完成。
- ELLIPSE/EL 通过第一轴两个端点和另一半轴长度创建真实旋转椭圆，构造过程提供轴线和
  曲线动态预览；实体支持属性、点选/框选、范围缩放、基础变换、中心及四轴端夹点、
  中心/象限/最近捕捉，并随 `.smartcad` v15 和 DXF ELLIPSE 无损往返。
- SPLINE/SPL 通过四个控制点创建三次 Bézier 形式样条；输入前三点时显示控制多边形，
  第四点随光标实时显示最终曲线。命令支持 U 放弃输入点，提交进入单事务；实体沿用已有
  属性、选择、近似长度、端点/中点/最近捕捉、四控制点夹点、基础变换和原生保存能力。
- SPLINEDIT/SPE 可拾取控制点后动态预览并移动，也可输入 `MOVE 1-4 X Y` 精确修改；
  支持 REVERSE 和 `POLYLINE 4-4096` 受控精度转换。每次修改独立成事务，U 可放弃，
  Ribbon 使用独立主题图标。
- MTEXT/MT 提供粗体、斜体、下划线富文本编辑器、边界宽度、文字高度与左右/居中/
  两端对齐；TEXTALIGN 控制单行文字对齐。STYLE 支持字体族、固定高度、宽度因子、
  倾斜角、粗斜体和当前样式，样式修改可撤销。MLEADER/ML 通过箭头、折点和文字落点
  三点创建并全程预览；三类功能均有专属主题图标和 `.smartcad` v17 持久化。
- CIRCLE 支持圆心-半径、圆心-直径、2P 和 3P；ARC 支持 3P、CSE、SCE，以及
  SCA/CSA（起点或圆心加包含角）、SEA（起点-端点-角度）、SED（起点-端点-切线方向）和
  SER（起点-端点-半径）。角度、方向和半径既可由视口第三点确定，也可用
  `ARC SCA|CSA|SEA|SED|SER 数值` 精确输入。Ribbon 下拉项均带主题图标，所有方式都有
  阶段提示、动态最终曲线预览、U 放弃点、单事务撤销和几何/交互自动测试。
- CIRCLE TTR 支持以指定半径与任意两条直线、圆或圆弧相切；求解器枚举外切/内切和
  两侧偏移候选，过滤圆弧有效区间，再按两次拾取位置选择预期结果。CIRCLE TTT 使用
  解析广义阿波罗尼斯求解，覆盖直线、圆、圆弧任意三对象组合、内外切和圆弧区间过滤。
  两者在最后一个对象悬停时显示完整圆预览，所选支撑对象
  高亮，最终通过“创建相切圆”单事务提交；命令为 `CIRCLE TTR 半径`、`CIRCLE TTT`，
  Ribbon 圆按钮下拉菜单提供对应主题图标入口。
- 移动、旋转、偏移、修剪、文字、线性标注和填充支持落图前几何预览；修改命令
  预览与最终事务共用几何计算，Ribbon 不再保留冗余“选择”按钮。
- 点选、窗口框选、交叉框选和 Shift 追加选择；单选和多选均使用实体属性目录树，
  可查看常规属性、坐标、长度、角度、半径、面积、文字和顶点等数据。
- 选择集支持批量改层并通过统一事务撤销/重做，以及移动、复制、旋转、参考缩放、
  镜像复制、删除、直线修剪和直线/圆/圆弧偏移；新增修改命令均有动态预览、
  Ribbon 专属图标和 COPY/CO、SCALE/SC、MIRROR/MI 命令别名。
- ALIGN/AL 支持为整个选择集依次指定两组源点和目标点，一次完成平移、旋转与等比缩放；
  已指定第一组点后显示平移预览，指定第二源点后显示完整对齐预览，最终以单事务提交。
- 有限曲线边界延伸、直线/圆/圆弧两点打断、任意顺序连续直线合并，以及多段线/填充边界
  分解已形成命令闭环；支持 EXTEND/EX、BREAK/BR、JOIN/J、EXPLODE/X、动态预览、
  事务撤销/重做和自动测试。
- STRETCH/S 支持交叉窗口选择控制点并局部拉伸直线、多段线、填充边界和线性标注；
  圆、圆弧和文字在基准点落入窗口时整体移动，窗口、位移和最终几何均有动态预览。
- 多功能夹点编辑支持直线端点/中点、圆心/半径、圆弧中心/端点/半径、多段线顶点、
  文字插入点、标注控制点和填充边界顶点；选择后显示主题感知蓝色夹点，拖动时预览，
  松开后以单事务提交并支持撤销。拉伸只修改活动实体；移动、旋转、缩放和镜像会同步
  变换整个选择集，拖动期间可按 Space 循环模式。Ribbon 菜单和
  GRIP_STRETCH/GRIP、GRIP_MOVE/GM、GRIP_ROTATE/GR、GRIP_SCALE/GS、
  GRIP_MIRROR/GMI 均可直接选择模式。
- LENGTHEN/LEN 支持按拾取端动态拉长或缩短直线、圆弧和开放多段线；直线端点沿原方向
  投影，圆弧端点保持半径，含 bulge 的多段线端弧保持圆心和圆弧编码。悬停、结果预览、
  Ribbon 专属图标、事务撤销与自动测试均已覆盖。
- FILLET/F 支持直线、圆和圆弧的有效两两组合，按拾取侧生成真实相切圆弧并同步
  修剪或延伸直线/圆弧，使用 `FILLET R 数值` 设置半径；CHAMFER/CHA 支持直线
  拾取语义，使用
  `CHAMFER D 数值 数值` 设置两个倒角距离。两者均支持预览、事务撤销和属性继承。
  CHAMFER 选择多段线时可一次处理开放或闭合多段线全部角点，并阻止相邻倒角重叠。
  CHAMFER 还支持直线—圆弧及圆弧—圆弧组合，双距离沿各实体曲线长度计算并按拾取侧
  保留。BLEND/BL 可在直线、圆弧和已有样条的端部间创建切向连续三次样条，提供专属
  图标、动态预览、属性、捕捉、夹点和全部基础变换。
  FILLET 选择多段线时生成真实 bulge 圆弧段；弧段支持 `.smartcad`、DXF、绘制、拾取、
  对象捕捉、镜像和 EXPLODE，不会离散化为折线；JOIN 会保留并按路径方向翻转 bulge，
  开放多段线端部弧段可继续 EXTEND。
- ARRAYRECT/AR 支持对预选的单个或多个实体创建关联矩形阵列，使用
  `ARRAYRECT 列数 行数` 配置规模，通过基点和第二点交互确定带方向的列/行间距，
  提供完整阵列预览、属性继承、项目数保护和单事务撤销。
- ARRAYPOLAR/AP 支持以交互中心点创建关联环形阵列，使用
  `ARRAYPOLAR 项目数 填充角` 配置完整圆、部分圆或反向阵列，支持多对象源、动态预览、
  属性继承、10000 副本保护和单事务撤销。
- ARRAYPATH/PA 支持沿直线或多段线对单个/多个源对象进行等弧长分布，使用
  `ARRAYPATH 项目数 ALIGN|NOALIGN` 控制项目数量和切线对齐；源基点映射、路径悬停
  预览、开放/闭合路径、原实体重新定位和副本创建统一位于一次可撤销事务中。
- 三类阵列成员保存稳定阵列 ID、源几何、项目索引和完整参数；点选任一成员会选择整组。
  Ribbon 提供专属“编辑阵列”图标和悬停整组预览，`ARRAYEDIT/AE` 支持
  `RECT 列 行 列距 行距`、`POLAR 项目数 填充角`、`PATH 项目数 ALIGN|NOALIGN`，增删成员
  与参数重生成位于一次可撤销事务。`.smartcad` v16 无损往返；DXF 展开为普通实体并报告
  关联关系降级。
- TRIM/TR 已从直线—直线扩展到直线、圆和圆弧之间的有限边界裁剪。圆目标会转换为
  保留圆弧；目标中段被删除时可生成两条直线或两段圆弧，全部结果、动态预览与最终
  事务使用同一几何求解，支持一次撤销恢复原实体。开放/闭合多段线中的正负 bulge
  弧段也可直接裁剪，部分弧仍使用 bulge 表达，并保留未裁弧段、图层和线宽。
- EXTEND/EX 支持根据目标拾取端延伸直线或圆弧，并可使用有限直线、圆或圆弧作为
  边界；候选交点会过滤边界范围和已有圆弧区间，选择同方向最近交点。预览、提交、
  属性保持和撤销均已覆盖，闭合圆不会被错误当作可延伸目标。
- 端点、中点、圆心、象限点、交点、垂足、切点和最近点对象捕捉，带类型标记和
  中文提示；进一步支持有限线段外的外观交点、延伸捕捉和相对参考点平行捕捉；
  对象追踪可从已捕获特征点生成水平/垂直引导和多点交汇，支持 F11、状态栏及
  OTRACK ON/OFF；同时支持栅格、正交、线宽显示、平移和缩放范围。
- F10 极轴追踪按 1–90° 可配置增量吸附，接近追踪角时显示贯穿视口的主题引导线和
  角度标签；F9 捕捉模式按可配置 X/Y 等间距吸附。两者提供 Ribbon/状态栏图标、
  `POLAR ON|OFF`、`POLAR ANGLE 数值`、`SNAP ON|OFF`、`SNAP 数值` 和
  `GRID SPACING 数值` 命令，设置随工作区持久化；正交与极轴追踪互斥。
- 图形单位对话框支持无单位、毫米、厘米、米、英寸和英尺，角度支持十进制度数、
  度分秒、百分度和弧度，并分别设置 0–8 位显示精度。Ribbon 使用主题设置图标；
  命令支持 `UNITS`、`UNITS MM|CM|M|INCH|FEET|UNITLESS`、
  `ANGLEFORMAT DECIMAL|DMS|GRADS|RADIANS`、`LUPREC`、`AUPREC`。修改以事务提交，
  可撤销重做，状态栏即时按单位显示，并随 `.smartcad` v12 清单无损保存。
- 栅格支持任意角度旋转及 Left/Top/Right 三种等轴测平面；捕捉在对应斜交基向量中
  求解并量化，不以屏幕近似替代。F5 循环等轴测平面，Ribbon/状态栏使用主题栅格
  图标；命令支持 `GRID ROTATION 角度`、`SNAP ISOMETRIC` 和
  `ISOPLANE LEFT|TOP|RIGHT|OFF`，旋转与平面选择随工作区持久化。
- 新建、打开、保存、另存为、撤销、重做和原子保存。
- 位图矢量化使用水平同色游程、相邻行长条并集和整数端点闭合生成严格四邻域色块；
  小图自动使用单线程，大图并行提取游程与行间关系，单/多线程生成字节一致的 SVG。
  Release 批量工具历史上对 1000 张多尺寸、多拓扑 PNG 执行四邻域基线、拆分单线程和
  拆分多线程的精确回栅格、SVG 重解析与性能比较，记录为 1000/1000 通过。原固定图片与
  HTML/manifest 已移除；当前合成图案生成器需重新测量，不承诺完全复现旧输入与结果。

- `.vectorpath` 原生格式版本 24（兼容旧 `.smartcam`、`.smartcad` 扩展名），支持全部当前实体、三次样条、椭圆、关联阵列、完整图层属性与冻结、命名图层状态、
  图层线型/透明度、实体/图层线宽、稳定实体 ID、多段线 bulge、图形单位和角度格式，

- DXF R2018 LINE、CIRCLE、ARC、LWPOLYLINE、TEXT 读写，支持图层名和 LWPOLYLINE
  组码 42、40、41 往返。
- 图层表支持新建、受保护删除、当前层切换、显隐、锁定、颜色、线宽和打印控制；视口按

- 图层面板新增重命名、合并和“删除含内容”；操作会同时更新实体归属和当前图层，

  `LAYER RENAME 源 新名`、`LAYMRG 源 目标` 和 `LAYDEL 图层`。
- 图层面板支持冻结/解冻与隔离，当前图层不能冻结；图层可见、锁定、颜色、线宽、

- 图层线型支持 Continuous、Dashed、Dotted、DashDot、Center 和 Hidden，透明度支持
  0–90%；面板修改立即反映到视口，并随撤销、命名图层状态和 `.smartcad` v12 往返。

- 命令别名、`.scr` 顺序执行和内置命令帮助；命令行支持绝对 `X,Y`、相对直角
  `@dx,dy` 和相对极坐标 `@距离<角度`，参考点依次取当前多点输入的最后一点或工具

  “精确坐标”使用主题命令行图标并可通过 Ctrl+L 聚焦输入。
- 命令行输入提供不区分大小写的弹出建议和 Tab 补全，Up/Down 浏览本次会话历史；
  PLINE 支持 `CLOSE/C`、`UNDO/U`、`DONE/ENTER`，LINE 支持 `CLOSE/C` 与逐段

  活动命令关键字优先于同名顶层别名；闭合多段线/直线链通过事务提交，可撤销重做，

- `Delete`、`Ctrl+A`、`Esc`、`Space/Enter`、`F3/F7/F8` 以及
  `Ctrl+1/Ctrl+3/Ctrl+9` 常用快捷键。

## 已知降级

- 当前只有模型视图，没有图纸空间布局、布局视口、比例锁定或相应持久化操作；保留的
  `space_name` 兼容字段不构成布局功能。
- 输出当前仅保留 CTB/STB 解析、颜色/线宽映射辅助和 `PLOTSTYLE` / `STYLESMANAGER`
  文件管理。页面设置、打印预览、系统打印机、PDF 导出与批量发布均无可调用实现，不能标为已完成。

- 文件生命周期支持五分钟自动保存、最多五份恢复副本、命名/未命名图形恢复管理器和
  AUDIT CHECK/FIX。恢复副本通过 `QSaveFile` 原子写入且不改变活动文档路径/修改状态；
  审计可移除无效几何、修复随层线宽和多段线段数组，并以单事务撤销。

- 标注和填充已支持 `.smartcad` 无损保存及基础 DXF DIMENSION/HATCH 往返；样条曲线、
  多重引线、布局和未知 DXF 记录仍会进入兼容性报告。块功能已按用户要求移除。
- DWG 通过 GNU LibreDWG 0.14 外部进程隔离转换；基础二维实体可导入并按 R2000
  导出，代理对象、布局和未映射字段尚不能原样往返。
- 套索、栏选、多边形选择和选择循环尚未实现。
- 修剪支持直线、圆、圆弧和含 bulge 多段线目标；延伸支持直线、圆弧和开放多段线
  端部目标；圆和圆弧打断已实现；同圆连续圆弧可合并为圆弧或完整圆；直线和开放
  多段线可混合合并为开放或闭合多段线。
- 分解支持多段线、填充边界和标注；复杂对象仍按兼容性报告中的降级规则处理。
- 偏移支持直线、圆、圆弧、开放/闭合多段线以及三次样条；多段线 bulge 圆弧按 5°
  最大步长受控细分，样条按模型尺寸自适应细分为高精度多段线。尖角采用受限斜接或
  斜切连接，并清理偏移造成的局部自交；结果保留源图层和实体线宽。
